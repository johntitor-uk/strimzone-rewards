# Collections

Aqui van packs, sagas, colecciones grandes y eventos.

Usa estas carpetas:

- movie_sagas: sagas de peliculas
- series_sagas: colecciones de series
- anime_sagas: colecciones de anime
- events: eventos temporales

Regla:
Los rewards de pack deben tener collectionId.
Los rewards individuales no deben tener collectionId de pack.
