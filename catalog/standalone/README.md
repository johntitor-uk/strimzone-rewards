# Standalone rewards

Aqui van premios individuales fuera de packs.

Ejemplos:

- movies/105.json
- series/1396/base.json
- series/1396/season_1.json
- series/1396/s01e01.json
- anime/1429/base.json

Regla:
No pongas collectionId si el reward no pertenece a un pack.
Usa unlockRule.contentId para conectar el premio al contenido.
